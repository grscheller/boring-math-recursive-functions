# Boring Math - Recursive Functions

Project is to explore different ways to efficiently implement recursion
in Python.

PyPI project
[boring-math-recursive-functions](https://pypi.org/project/boring-math-recursive-functions).

This pypi project is part of the
[boring math](https://grscheller.github.io/boring-math) projects.

## Documentation

Documentation and other links for this project are hosted on
[GitHub Pages](https://grscheller.github.io/boring-math/projects/recursive_functions.html).

Functions defined using previously well defined values originating from
"base cases" are called "primitively recursive functions." Not all
computable functions are primitively recursive.
